# Feedback 016: 정책 결정은 유저에게 질문 후 확정

## Rule

마진 모드, 마크 프라이스 정의, 청산 정책, 펀딩 주기/산식, 보험기금 유무 같은 **제품/정책 결정**은 에이전트가 추천안으로 확정하지 않는다. 선택지와 트레이드오프를 정리해 유저에게 먼저 질문하고, 답을 받은 뒤 ADR로 확정한다.

## Why

- 이런 결정은 코드베이스나 컨벤션에서 도출할 수 없는 거래소의 제품 정체성·리스크 정책에 속한다. 잘못 확정하면 구현 전체가 뒤집힌다.
- 에이전트의 기본값은 "업계 표준(Binance) 추종"으로 기울기 쉬운데, 이 프로젝트의 맥락(외부 오라클 없는 폐쇄 거래소, 단일 개발자 MVP)과 다를 수 있다.

## How to apply

- 계획/ADR 작성 중 정책 선택지가 나오면: 선택지 + 트레이드오프 + 추천안을 정리해 유저에게 묻는다. 추천은 하되 확정은 유저가 한다.
- 기술적 구현 방식(폴더 구조, 패턴 재사용, 정산 메커니즘 등)은 기존 ADR/컨벤션에서 도출 가능하면 묻지 않는다.
- 경계 기준: "이 결정이 거래소 운영자의 비즈니스 선택인가, 코드베이스에서 도출 가능한 엔지니어링 선택인가".
