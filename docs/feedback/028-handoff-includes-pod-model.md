# 028 — 핸드오프/캠페인 문서에는 포드 위임 모델을 명시한다

**Rule**: 세션 핸드오프·캠페인 계획 문서에는 운영 모델을 반드시 포함한다 — "메인은 오퍼레이터(기획·선별·검증), 실행은 Opus 서브에이전트 포드에 위임, 포드는 아끼지 말고 많이·병렬로". 상태·교훈만 적고 일하는 방식을 빠뜨리면 안 된다.

**Why**: 2026-07-14 handoff 초안에 시스템 상태·교훈·체크리스트는 있었지만 포드 위임 모델이 빠져 유저가 교정. 이 모델은 유저가 반복 지정한 것(07-13 "실행은 opus한테", 07-14 "더 많은 subagent 돌려서")으로, 새 세션이 이를 모르면 메인 컨텍스트로 실행까지 하며 토큰을 태우고 병렬성을 잃는다.

**How to apply**: 핸드오프 프롬프트 블록에 운영 모델 1줄 + 상세 섹션(포드 유형 카탈로그, 브리핑 표준 5요소, 동시 출격 관행, 넛지 회복 팁). 인수인계 메모(handoff-2026-07-14, 비공개 study/)의 "포드 운용" 섹션이 템플릿.
