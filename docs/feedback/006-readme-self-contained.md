# Feedback-006: README는 자체 완결적이어야 함

## Rule
README는 외부 문서(ADR 등)를 참조하지 말고 그 자체로 완결되어야 한다.

## Why
README를 읽는 사람이 다른 문서를 따라가야 한다면 README의 역할을 못 한다. 프로젝트의 진입점은 모든 핵심 정보를 직접 담고 있어야 한다.

## How to apply
- README 본문에 모든 핵심 정보(구조, 설정, 실행, 메시지 포맷 등)를 직접 작성
- ADR은 결정의 근거와 맥락을 위한 보조 문서이므로 README가 ADR을 참조하지 않는다
- 중복이 발생해도 README는 자체 완결을 우선
