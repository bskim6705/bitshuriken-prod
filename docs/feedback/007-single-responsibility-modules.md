# Feedback-007: 도메인 객체는 단일 책임 모듈로 분리

## Rule
별도의 도메인 의미를 갖는 데이터 클래스는 자체 모듈로 분리한다. 한 파일에 여러 핵심 클래스를 모아 두지 않는다.

## Why
모듈을 도메인 단위로 나누면 import 경로가 명확해지고, 향후 클래스가 커질 때 자연스럽게 확장된다. 매칭엔진의 Order/Trade처럼 1급 객체는 자체 파일을 가져야 한다.

## How to apply
- `engine/order.py`, `engine/trade.py` 같이 핵심 도메인 객체는 자체 파일
- 메모리 최적화가 필요한 인스턴스(Order, Trade)는 `__slots__` 함께 적용
- 부수적인 enum/유틸리티는 도메인 객체와 같은 파일에 둘 수 있음
