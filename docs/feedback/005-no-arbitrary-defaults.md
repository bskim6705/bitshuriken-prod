# Feedback-005: 함부로 default 값을 쓰지 말 것

## Rule
DTO/메시지/함수 파라미터에 default 값을 함부로 지정하지 않는다. 의미적으로 명확한 기본값이 있는 경우에만 사용한다.

## Why
숨겨진 default는 호출자가 필드를 누락해도 통과시켜 의도치 않은 동작을 유발한다. 특히 거래소 도메인에서는 누락이 심각한 결과로 이어질 수 있다.

## How to apply
- DTO/메시지 클래스: 모든 필드를 명시적으로 받도록 정의 (특히 외부에서 들어오는 데이터)
- 도메인적으로 명백한 default(예: `OrderStatus.OPEN`)는 허용
- 애매하면 default를 빼고 호출자가 명시하게 만든다
