# ADR-002: 단일 매칭엔진 + MarketType별 전후 처리 분기

## Status
Accepted

## Context
spot과 futures 매칭엔진을 분리할지, 하나로 통합할지 결정이 필요하다.

## Decision
매칭엔진은 하나로 유지하고, 체결 전후 처리를 MarketType에 따라 분기한다.

## Rationale
- **핵심 매칭 로직은 동일**: 가격-시간 우선순위 오더북 매칭은 spot/futures 모두 같다.
- **다른 부분은 전후 처리**: 잔고 확인(자산 vs 증거금), 체결 후 처리(자산 교환 vs 포지션), 청산/펀딩비 등.
- **엔진 분리 시 코드 중복**: 오더북, 체결, 부분 체결 등 핵심 로직이 두 곳에 존재하게 된다.

## Consequences
- 매칭엔진 코드베이스가 단일하여 유지보수가 쉽다.
- futures 전용 로직(청산, 펀딩비)은 별도 모듈로 분리하여 매칭 전후에 호출한다.
- 트래픽 증가 시 MarketType별로 인스턴스를 나눠 스케일링하는 것은 가능하다 (코드는 동일, 토픽만 분리).
