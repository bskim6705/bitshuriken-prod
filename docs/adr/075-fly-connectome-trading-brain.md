# 075. 초파리 커넥톰 트레이딩 뇌 — 별도 실험 프로젝트 `bitshuriken-prod-fly`

## Status
Accepted (2026-09-16), experimental

## Context
2026-09 구글 딥마인드/FlyWire 커넥톰 공개 이후 "초파리 뇌가 거래한다"(fly-trader, Flybrain, Stonkfly)류 실험이
퍼졌다. 유저 요청: 우리 거래소에서 agents의 규칙 전략 대신 초파리 뇌가 거래하는 것을 보고 싶다. 처음엔 agents의
전략 슬롯으로 구현했으나 유저가 별도 프로젝트로 분리를 지시했다 (feedback-029).

## Decision
- **위치**: `bitshuriken-prod-fly/` — 자기 package.json·데이터·대시보드(:5130)를 가진 독립 실험 프로젝트. agents
  코드를 import하지 않고 얇은 HMAC 클라이언트를 복제한다. 거래소에는 일반 유저 표면으로만 붙는다 (feedback-025).
- **뇌**: FlyWire FAFB v783 공개 버킷 데이터로 중앙뇌(시엽 제외) 41,750 뉴런 / 1,062,130 부호 시냅스를 굽고,
  leaky-tanh rate 네트워크로 bar당 4 스텝 전파. 시냅스 부호(Shiu 2024)·위상은 커넥톰 그대로, 크기는 뉴런별
  Lp(1.5) 정규화 × gain 0.9 (echo state 실측 조건).
- **입출력**: OHLCV 피처 12개 → ON/OFF 채널 → 감각 뉴런 집단(후각·미각·존스턴 기관·강모·온도). 판독은 하강뉴런
  1,305개의 ridge 선형 회귀(타깃: H bar 뒤 변동성 정규화 수익률). 뇌 안은 학습하지 않는다(reservoir).
- **거래**: spot 롱온리. ŷ → 노출 0..1, 데드밴드·최소 보유 bar로 churn 억제, 시장가 주문. 라이브·백테스트는 같은
  트레이더 객체.
- **평가**: `train`이 검증 IC·hit rate와 out-of-sample 백테스트(마지막 N일 미학습)를 항상 출력. 결과는
  docs/trading/journal.md에 기록. 성과를 주장하지 않는다.

## Rationale
- 분리: 실험은 수명·의존성(53MB 다운로드, 학습 파이프라인)·성숙도가 프레임워크와 다르다. 실패하면 통째로 버리고
  성공하면 유저 확정 후 승격한다. agents의 Strategy/컨트롤 API를 실험 하나를 위해 넓히지 않는다.
- 중앙뇌: 전체(139k)는 bar당 107ms vs 중앙뇌 18ms. 시각 입력을 쓰지 않으므로 시엽은 계산만 늘린다. `full`은 옵션.
- reservoir(고정 뇌 + 선형 판독): 커넥톰을 "그대로" 쓴다는 요구와 재현성(결정론, 학습 수 초)을 동시에 만족. 시냅스
  학습(역전파·MB 가소성)은 검증된 판독 위에서 다음 단계.
- Lp=1.5: p=1(Σ|w|=1)은 수축 보장이지만 깊은 층 활동이 소멸(하강뉴런 12%만 응답), p=2는 허브 폭주로 초기 상태 의존.
  1.5가 활동(73%)과 수렴을 동시에 만족했다. 매 학습 시 echoDiff 재측정으로 조건을 지킨다.

## Consequences
- 새 서비스 폴더·포트(5130)·데이터 디렉터리. 배포 정의(Dockerfile/compose)는 실험 단계라 없음 — 라이브는 로컬 실행.
- 라이브 유동성은 bots 미러에 의존(기존과 같음). 모델은 (심볼, interval) 단위라 interval 변경 시 재학습.
- 미해결: 선물/숏, 시각 입력(광수용체에 차트 투영), 버섯체 도파민 가소성 — 전부 판독의 예측력이 확인된 뒤 유저 확정.
