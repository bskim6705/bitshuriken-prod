# 078. fly v2 — 실시간 호가창 입력 + 단순 유전 선별

## Status
Accepted (2026-09-16), experimental — ADR-075를 확장

## Context
fly v1(1분봉 OHLCV 12 지표 → 커넥톰 → ridge 판독)은 검증 IC 0.04로 테이커 수수료 벽을 못 넘었다. 유저 방향
(feedback-032): 입력을 실시간 정보(가격·best depth 10~20·체결)로 바꾸고, 학습은 승률·수익 상위 파리를 남기고
돌연변이를 만드는 단순 진화로.

## Decision
- **데이터 경로**: 로컬 거래소 `/ws/market`의 `<sym>@depth`(전체 스냅샷 push)·`<sym>@trade` → 1초 샘플(top-20 양측 +
  그 사이 체결 + depth 갱신 수) → `data/lob/<SYMBOL>/<date>.jsonl` 기록(원시). 피처는 리플레이 때 다시 계산한다.
- **피처 27종**(`lob/features.ts`): 레벨 불균형(1/5/10/20), microprice, 서명 체결 흐름(1s/5s/30s), OFI(1s/5s),
  mid 수익률(1s~10m)·EMA 거리, 스프레드·깊이 비·양측 기울기·깊이 z, 체결 강도·갱신률·거래량 z, 변동성 국면·정적 시간.
  전부 유계, ON/OFF 정류 채널로 감각 집단에 배정(흐름=미각, 가격=후각, 형태=촉각, 활동=청각, 국면=온도).
- **뇌**: v1과 같은 커넥톰 rate 네트워크. 피처 세트는 주입식(`specsFor(inputKind)`), 감각 집단별 입력 배율은 유전자.
- **진화**(`evo/`): 파리 = 뇌 유전자(gain·leak·substeps·입력 세기/밀도/시드·정규화 지수·모달리티 배율) + 판독 유전자
  (지평 H초, λ) + 정책 유전자(θ_in·θ_out(ŷ 표준편차 배수)·최소 보유·비중). 평가 = 기록 리플레이: 앞 70%에서 ridge 판독,
  뒤 30%(지평만큼 purge)에서 임계 정책의 순수익(테이커 수수료 포함)·승률. 적합도 = 순수익% + (승률−0.5)×2, 거래
  minTrades 미만은 무효. 세대마다 상위 elite 보존 → 엘리트 돌연변이 + 신입 1. 자식 프로세스 풀로 병렬 평가.
- **배치**: 최우수 파리 → `data/models/<SYMBOL>-1s.json`(inputKind 'lob', 전 구간 재적합 판독, 정책 포함).
  `live`는 lob 모델이 있으면 실시간 모드(`trade/lob-live.ts`): 스트림 자체로 5분 warmup 후 임계 정책으로 시장가.
- **수수료는 파라미터**(`FLY_TAKER_FEE_BPS`, 기본 10): 적합도와 라이브 판단이 같은 값을 본다. 티어는 올리지 않는다 (feedback-031).
- **리그 = 라이브 컴피티션**(`league/`, feedback-031): N마리가 각자 서브계정·같은 자본·같은 수수료로 동시에 실시간 거래.
  시즌(기본 30분)마다 시즌 순수익 순위 → 하위 relegate 탈락(청산) → 상위 생존 파리의 돌연변이가 빈 슬롯 입장(판독은 최신
  기록으로 재적합, 자식 프로세스). 시즌 주문 수 < minTrades면 최하위(실격). 명예의 전당·시즌 이력을 `data/league/`에 보관,
  대시보드 `/`(league.html)에 순위표·강등 존·파리별 뇌 상태. 리플레이 `evolve`는 사전 예선/오프라인 탐색용으로 남는다.

## Rationale
- 원시 기록 + 리플레이 재계산: 피처 코드가 바뀌어도 기록이 유효하고, 평가가 결정론적이다.
- 뇌 유전자와 판독/정책 유전자를 나눈 이유: 뇌 궤적 계산이 비용의 전부(샘플당 ~20ms 무부하, 부하 시 ~80ms)라
  파리당 한 번만 돌리고 판독·정책은 그 위에서 싸게 평가한다.
- 적합도를 **뒤쪽 미학습 구간**에서만 재는 이유: 신호가 노이즈보다 작을 때 진화는 운을 학습한다. 워크포워드가 최소한의 방어.

## Consequences
- 진화는 기록 길이에 비례해 느리다(1h 기록 × 파리 16 × 세대 8 ≈ 부하 시 2~3h). 기록은 라이브와 별 프로세스로 계속 쌓는다.
- 1초 임계 정책은 테이커 10bps에서는 거의 진입하지 않게 진화한다(수수료 벽) — 수수료 티어(ADR-073) 결정이 선행 변수.
- 미해결: 메이커 주문(POST_ONLY) 실행, 세그먼트 경계 처리의 보수성, 라이브 warmup을 기록 리플레이로 대체(5분 단축).
