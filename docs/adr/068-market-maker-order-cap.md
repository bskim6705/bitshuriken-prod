# ADR-068: 시장조성 계정 오픈 주문 캡 상향

## Status
Accepted (2026-07-12, 유저 결정)

## Context
심볼당 오픈 주문 상한(`MAX_OPEN_ORDERS_PER_SYMBOL`=200)은 일반 유저 보호장치다. 미러 메이커는
50레벨×양사이드(정상 ~100)를 상시 유지하는데, 재시작 과도기(이전 인스턴스 취소가 엔진에서
드레인되는 동안 신규 인스턴스가 배치)와 고변동 churn의 in-flight 겹침으로 200에 닿아 place가
거절되는 순간이 관측됐다(자가 치유되나, 심볼 증설·깊이 확대 시 상시 충돌).

## Decision
`User.rateLimitExempt` 계정(=시장조성 계정, ADR-066에서 admin 표면으로 지정)은 상향 캡
`MM_MAX_OPEN_ORDERS_PER_SYMBOL`(=2000)을 적용한다. 무제한이 아니다 — 폭주 방어는 유지.
적용 지점: spot 주문, spot OCO(+2 규칙 동일), futures 주문. 유저 조회는 일반 캡(200) 도달
시에만 수행해 happy path 비용 0.

## Rationale
- `rateLimitExempt`는 이미 "시장조성 계정" 지정 플래그로 쓰이고 있어(ADR-066) 스키마 변경 없이
  같은 의미 축을 확장한다. 실거래소도 MM 계정에 별도 주문 한도를 부여한다.
- 상향 캡 2000 = 정상 상태(~100)의 20배 — 재시작 겹침·향후 깊이 확대를 흡수하면서도
  런어웨이 봇이 무한 주문을 쌓는 것은 여전히 차단.

## Consequences
- 스키마·마이그레이션 불필요. 봇 부팅 플로우 변경 없음(기존 exempt 지정이 곧 캡 상향).
- `rateLimitExempt`의 의미가 "레이트리밋 면제"에서 "시장조성 계정 특권(레이트리밋 + 주문 캡)"으로
  넓어짐 — 이름과 의미의 간극은 수용(컬럼 rename은 마이그레이션 대비 이득 없음).
