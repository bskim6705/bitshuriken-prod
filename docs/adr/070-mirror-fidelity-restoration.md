# ADR-070: 미러 충실도 복원 — 소스가 캡 IOC · 심볼당 MM 계정 · depth50 우선순위 · 선물 개시 범위

## Status
Accepted (2026-08-19)

## Context
07-12에 측정된 미러 충실도(top-of-book p99 0.22bps, 1분봉 H/L/C 0.00bps)는 depth50/rec150ms/TPS20
기준인데, 07-14 BE 병목(Wallet 행 락 컨보이) 때문에 depth10/rec600ms/TPS5로 디튠된 채 방치됐다.
그 병목은 ADR-069 S2(인메모리 원장)로 소멸했고(현 천장: Node 이벤트루프, 유효 100~120 TPS),
feedback-027의 "기본 50레벨" 규칙과 실제 설정이 어긋난 상태였다. 코드 감사에서 테이커가 소스
체결 가격을 버리는 구조(꼬리/캔들 미충실), maker/taker 단 2계정 구조(계정 단위 직렬화·지연 왜곡),
정확성 버그 다수(에러 은폐·피드 커서·자본 관리)가 확인됐다. 유저 확정(2026-08-19) 4건을 기록한다.

## Decision

### 1. 테이커 체결가 재현 = 소스 가격 캡 IOC
소스 체결 리플레이는 LIMIT IOC를 유지하되, 지정가를 로컬 touch가 아니라
**max(소스 체결가 워터마크, 로컬 touch)**(BUY; SELL은 min)로 둔다. 소스에서 여러 레벨을 관통한
스윕이 나면 로컬도 그 가격까지만 스윕한다 — 꼬리(wick)·캔들 OHLC가 충실해지고, 지정가가 구조적
상한이라 07-12의 "얕은 북 과도 스윕"(-1.3% 꼬리 아티팩트)은 재발 불가능하다. 워터마크는 사이드별로
버퍼에 쌓인 미방출 체결의 극값이며 flush 성공 시 리셋한다.

### 2. MM 계정은 (market, symbol)당 분리
maker/taker 각각 심볼당 독립 계정(`maker-{sym}@bots.local` 등, 선물은 `-f-` 접두). 근거:
- 2계정 구조는 전 심볼의 동결/정산/환불을 계정 단위로 직렬화해 봇 실측 지연을 왜곡한다 (유저 지적,
  관찰 #23의 잔여 구조). S2 이후에도 계정 단위 reserve 직렬화는 남는다.
- 정합성 체커는 계정 무관(F1~F4가 전 유저 대사)이라 체커 수정 불요. loadtest가 이미 N계정 선례.
- 펀딩은 계정당 자기 심볼 몫만. 부팅 시 잔고 확인 후 부족분만 충전(재시작마다 재mint 금지)하고,
  주기 리필 루프가 소진을 흡수한다.

### 3. 과부하 시 depth50 우선, 심볼 축소
feedback-027의 "기본 50레벨"이 규칙이다. S2 스택 실측에서 현 심볼셋 × depth50이 과부하면
depth를 낮추지 않고 심볼 수를 줄인다 (잔존 우선순위: BTC/ETH + KRW 마켓).

### 4. 선물 미러는 스팟 동반 심볼만 개시
FUTURES_SYMBOLS는 스팟도 미러 중인 심볼의 perp만 (초기 BTCUSDT/ETHUSDT). mark price가 로컬 스팟
체결에서 산출되므로 외부 오라클 불요. 선행 조건: ADR-037의 "perp 마켓주문 executedQty=0" 재검증.
스팟 없는 futures-only 심볼(관찰 #20)은 외부 오라클 정책이 확정될 때까지 범위 밖.

## Rationale
- 실거래소 기준(feedback-024)에서 "제대로 된 미러"의 판정은 가격·타이밍 충실도다 (07-12 유저:
  볼륨 충실도보다 우선). 소스가 캡 IOC는 이 우선순위 안에서 꼬리 재현을 회복하는 최소 변경.
- 계정 분리는 봇 설정만으로 BE 무중단 적용 가능 (관찰 #23 fix ①), 정밀도 실측의 전제 조건.

## Consequences
- 봇 계정 수 = 2 × 미러 심볼 수. 부팅 시퀀스가 길어지고(계정당 signup/키/면제/펀딩) API 키가
  계정당 발급된다 — 키는 로컬 상태 파일로 재사용해 무한 증식을 막는다.
- 07-12 충실도 수치는 재측정 전까지 무효로 취급한다. 재현 가능한 벤치(`npm run bench`: top-of-book
  편차 percentile·1분봉 H/L/C·볼륨 비율)를 봇 레포에 신설하고, 이후 충실도 주장에는 벤치 결과를
  첨부한다.
- 볼륨·체결 건수 분포는 여전히 비충실(TPS 캡 하 집계 리플레이) — 알려진 한계로 명시.
