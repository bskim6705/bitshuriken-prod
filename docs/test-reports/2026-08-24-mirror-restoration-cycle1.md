## 3. 발견·수정 (적대검증이 잡아낸 것)
1. **유령 호가** (실거래소 위반): 셧다운이 BE 백로그 중이면 취소가 10s 타임아웃 → 조용히 삼켜져 미러 중단 심볼에 90+건/심볼 잔존, 벤치까지 오염. **수정**: maker.clear() 검증+재시도(비동기 취소 대기 포함), `npm run sweep`(전 봇 계정 잔존 주문 청소, 유저 표면만 사용). 실측: sweep 후 잔존 0, 신형 clear 실전 통과(ghost 0).
2. **선물 미러 3중 구조 결함** (한 번도 가동된 적 없던 이유):
   - ① fitNotional이 매 패스 스케일 재계산 → 외부 총액 지터에 전 레벨 동시 교체(주문 수명 0.4~0.8s, 북 공백). **수정**: 사이드별 sticky scale(±tolerance 내 재사용).
   - ② BE maxNotional 캡(포지션+미체결+신규 ≤ 1M/심볼, 방향 무시) vs 사이드당 예산 40%×2+겹침 > 1M. **수정**: 25%로 축소.
   - ③ **포지션 데드락**: 테이커 리플레이 체결로 maker/taker가 정확히 반대 포지션 축적 → 4계정 전부 노셔널 ~1.0M 고정 → 메이커 전 호가 거절 + 빈 북이라 감량 불가. **수정**(실거래소 MM의 인벤토리 관리 재현): 테이커 5s 주기 reduceOnly IOC flatten(0.3×캡 초과 시 0.15×캡까지) + 메이커는 감량 방향 호가를 reduceOnly로 게시(캡 면제·|포지션| 50% 클램프) — 한 흐름이 양 계정을 대칭으로 언와인드. 구 warnOnce가 이 전 과정을 침묵시켰던 것도 확인(수정 후 즉시 표면화).
3. **USDTKRW base 펀딩 부족**: 스테이블 base는 Binance 조회 불가 → 100k 플로어 → Upbit 한 레벨(350k)도 못 받침. **수정**: 스테이블 base 타깃 20M.
4. **벤치 프로브 결함**: 시작 시 1회 프로브가 순간 편측 북을 만나면 심볼 영구 제외(ETHUSDT·선물 누락 원인). **수정**: 3회 재시도 프로브.
5. be-futures 콜드부팅 P2028 (S2 baseline tx 5s 타임아웃) — 재시도로 통과, 재발 시 tx 타임아웃 상향 (BE측, 미수정).

## 6. 남은 것 (사이클 2 입력)
- **bench 프로브**: 부팅 시 3회 재시도로도 churn 순간 편측 북에 걸려 심볼 영구 제외(ETHUSDT 2회 연속·F:BTCUSDT) → 부팅 필터 폐지, 틱별 판정+샘플 수 보고로 전환
- **reduceOnly 클램프 레이스**: 5s stale 포지션 기준 클램프가 flatten과 경합 → "reduceOnly qty exceeds remaining position" 간헐 거절(BE가 안전 차단, 금전 무해). flatten 루프의 라이브 포지션 공유로 개선
- **방향 무시 캡 × in-flight 이중계상**: 교체 중 구주문+신주문 동시 계상으로 임계 근처 간헐 거절 → 임계 근처에서 replace를 cancel-확인-후-place로 전환하거나 BE 캡의 방향별 계산(실거래소 방식) 정책 검토(유저 결정)
- clear() 오탐: 검증 리드가 비동기 취소를 앞지름(7건, 실제 유령 0) → 검증 창 연장
- 페이싱 vs 충실도: rec300/TPS10의 p99 4~6bps가 스캘핑 테스트 기준으로 충분한지 **유저 확인 필요**. 더 조이려면 M1(정산 프로세스 분리, ~300 TPS 전망) 선행
- 심볼 예산 실측: 활발 심볼 기준 spot 앱 6~8·futures 앱 3~4 추정 (M1 후 2~3배 전망)
- 적대 리뷰 에이전트 3연속 529로 전체 리포트 미수령 — 핵심 공격 포인트는 인라인 검증 완료, 전량 재실행은 사이클 2에서
