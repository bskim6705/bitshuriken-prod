# 신박한 고빈도 전략 = 정합성 버그 헌팅 (2026-07-12, 5차)

전제(유저): 충실한 미러 + 대칭 수수료(maker=taker=10bps)에선 **어떤 전략도 알파가 없어야** 한다
(4차에서 실증). 따라서 **꾸준히 수익 내는 전략이 나오면 그건 곧 돈-창조 버그 신호**다 — 공격적 HFT를
버그 헌팅 도구로 쓴다. 돈-창조 표면 3곳을 신박한 프로브로 두드렸다.

## 프로브 3종 (agents `src/probe/*`, `npm run probe:*`)
| 프로브 | 두드린 표면 | 방법 | 결과 |
| --- | --- | --- | --- |
| **precision** | MARKET BUY(quote) dust 환불 + 라운딩 | 적대적 quote로 buy→sell 왕복 반복, 정착 후 총가치 측정 | net −41(BTC)/−82(SOL) USDT → **clean** |
| **churn** | 락 회계 / 취소-발주 레이스 (obs #12/#17) | 시장 밖 GTC를 발주 즉시 취소 초고속 반복 | **13,326 레이스, cancelErr 0, 락 고착 0** → clean |
| **selfcross** | 자전 체결 정산 보존 | 내 두 서브계정이 빈 책(AAVEUSDT)에서 서로 체결 | 350회, Δ=**−7.00 USDT=수수료** → clean |
| **fee** | 수수료 라운딩(초소액 면제) | minNotional 거래의 commission을 원장에서 직접 측정 | 86건, zeroFee 0, **실질 9.991bps**(명목 10) → clean |

selfcross는 **listed-but-unmirrored TRADING 심볼을 자동 탐색**(A가 시험 주문 후 취소로 확인)해 미러
메이커 없는 빈 책을 확보. B가 base 펀딩받아 SELL을 걸고 A가 크로스 → 순수 자전 체결.

## 판정 — 모든 돈-창조 표면 clean
프로브 부하(13k 취소 + 수백 마켓 왕복 + 350 자전 체결) 후 **거래소 전체 F1~F4 전부 ✓, 0 monetary fail**.
- **F1b**: 자전거래 A·B 포함 전 지갑이 원장에 대사 — 자전 체결이 돈을 창조하지 않음.
- **F4**: 13,326 취소 레이스 후에도 락=미체결주문 (레이스로 새는 락 없음).
- selfcross Δ가 정확히 수수료(350×20×0.5×20bps=7.00) — 자전 체결 수수료 징수도 정확.

## 핵심 방법론 발견 — async 정산의 "유령 수익"
precision 프로브가 개별 사이클에서 **+73 / +6.50 USDT "GAIN"을 반복 플래그**했으나 전부 거짓양성이었다:
async 정산(엔진→Kafka→워커)이라 **point-in-time 잔고 스냅샷**이 이웃/직전 거래의 지연 정산을 잡아 한
사이클의 델타를 오염시킨다(단일 심볼·"quiesce"로도 정산 시작 전 두 번 읽으면 옛 값이 안정처럼 보임).
**정착(드레인) 후 측정하면 전부 사라진다** — net은 항상 강하게 음수, F1b는 항상 green.
→ **신뢰 가능한 신호 = 다수 사이클 누적 net + 정착 후 F1~F4.** point-in-time PnL은 async 거래소에서
버그 판정 근거가 될 수 없다. 이것이 유저의 "수익 발견 시 정합성부터 의심하고 체커로 판별" 규율이
필수인 이유다(feedback-026 연장). 3차의 테이커 폭주버그·이번 유령 수익 모두 같은 async 뿌리.
